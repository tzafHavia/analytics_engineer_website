## Architecture Decision: Tab Navigation

Use **URL-based tabs via `searchParams`** (`?tab=sales`, `?tab=inventory`, etc.).

**Why:** Dashboard `page.js` is a Next.js Server Component. Keeping tabs in the URL means:
- Each tab fetches only its own data server-side (no over-fetching)
- Deep-linking works out of the box
- No `'use client'` wrapper needed on the page

**How:** Add a `tab` param alongside existing filters. The page reads `searchParams.tab`, renders a `<TabNav>` client component for switching, and conditionally renders the active tab's sections.
